>**GRAMMAR**

Undersanding grammar and common difficulties for ESL/EFL students is crucial to becoming and effective teacher 

---

>**SHOULD WE TEACH GRAMMAR?**

Long debate if including grammar is effective 

First learn trial-and-error 
- not specific grammar rules 
- direct grammar instruction 

*Weaver* - rarely translates to grammatical accuracy in oral / written output 

*Norris-Ortega* - explicit classroom grammar instruction can be highly effective 

Important question - not whether we should teach grammar but **how**

Weaver - teaching grammar from other skills is *not* effective as incorporating grammar in all areas / skills instruction 

Teacher should always consider how incorporate grammar in skill-based lessons 

Grammar instruction should complement communicative aims 

Young learners instructions not as explicit as for adults - presentation of language patterns used often more than metalangauge 

---

>**GRAMMATICAL UNDERSTANDING - MEANING / FORM / USE**

Grammar structures - 3 main aspects: 
- form
- meaning 
- use 

More clear teaching by decomposing 

**Meaning**:

Each structure has own semantic meaning - what structure communicates 

"Anna is singing" - present continuous: action started before + occurring now 

"Anna sings" - present simple: regular habit 


**Form**: 

When teach form - focus on written / spoken pattern of structure 

"Anna is singing" - subj + am/is/are + verb-ing 

Other aspect of form - pronunciation

Might focus on contractions 


**Use**: 

When it is appropriate to use structure 

Present continuous - when narrating events in progress 



-> To cover all 3 aspects - structure must be taught in contexts where naturally used 

Provide students with situational examples - both meaning / use through which highlight form

>**CONTROLLED EXERCISES**

Once presented grammatical form - use dynamics / interactive activities to further comprehension 

Practice stage of PPP - where practice target language via controlled ex. 

Include several tasks - progress from easy (input-based comprehension) to difficult (open-ended tasks production)

*Exercises*: 
- fill-in
- ordering activities 
- transformation task 
- sentence completion 
- short answer question 
- ...

Practice stage-dynamic: 
- interact with grammar form ia severl skills (read/listen/speak/write)
- and different class groupings (individual/pairs/groups)
- and incorporate meaning /form / use 

---

>**COMMUNICATINVE OUTPUT**

Once exposed to input and practiced exercises - start using grammar 

PPP lesson - production stage - use targer lagnugage to communicate oral / write 

Teacher - set clear context to use grammar: students prepared to communicate meaning using grammar presented 

*Writing*:
- write paragraph with specific communicative purpose (morning routine / tell story)
- write email / letter (cover letter / postcard)

*Speaking*: 
- student-student level production: required good level speak/listen 
- important to use real scenarios 
- students speak spontaneously - give short time to prepare 
- role plays (problem / negotiation)

---

>**ASSESSMENTE OF GRAMMAR**

Assessment of grammar must have validity - meaning that reflect class activities so keep exercises similiar to class activities 

Grammar assessed more implicitly and within context of speaking/writing 

Grammatical accuracy - part of students assessment 

Images can also be used as assessment technique 

Error analysis correction can also be used for grammar assessment
