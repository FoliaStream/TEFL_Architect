# CHAPTER 2 - Creating a Student-Centered Class

**Student-centered classroom** - Where students are encouraged to actively participate // motivated to study

>**TEACHER'S ROLE IN A STUDENT-CENTERED CLASSROOM**

*Teacher* - provides all necessary info

*Learning* requires students to participate - "You can lead the horse to the river, but can't make it drink"

Passive students - no benefit from learning 

-> Teacher is only a **facilitator**: involve / motivate / create enthusiasm

Can also be a mentor / referee / evaluator 

Students can only be helped to learn -> encourage them to develop 

Approach valid at all LEVELS

- *Importance of teacher preparation*

Teacher responsible for preparation - structured activities for pair / group

*In class*:
- set up activities
- monitor students
- give feedback 

*Group activities*:
- work with peers
- present
- review


**Do not lose control over the class**:
- Give specific task to complete
- Each group:
    - Small activity / project
    - Present result (speaking)
    - Prepare written report (writing)

**Group work may get noisy**:
- Noise is not always bad but keep order
- excitement = talk / involvement

**Improntance of techer reflection**
- Feedback important - yours / other students
- Use ideas from them 
- Each class unique so try new things and reflect


---

>**AUTONOMOUS LEARNING**

*Autonomous Learning*: students take responsiblity for their own learning 

*Teacher Role*: 
- make them understand they succeed only if they are active and participating
- help them understand they are studying for themselves

Stay open to students suggestions on discussions / reads / writes / exams

Student-centered class - questions to be answered together:
1. **Content** - what knowledge and skills will be studied
2. **Process** - what materials / procedures to be used 
3. **Product** - what will students produce to demonstrate learn?
4. **Evaluation** - how to assess learning

Anyway important to present material / activities clear and well structured 

Encouraging autonomou learning is a *gradual* process -> start - students set goals (help motivation) to be more willing to take responsibility and awareness


---

>**COOPERATION AND COLLABORATIVE LEARNING**

*Students-centered classroom* - where students' collaboration / cooperative learning are encouraged 

Need to communicate with peers -> independent of teacher

**Other students = resources**

*Cooperative learning* 
- use each other's resource / skills
- teach them how to take responsibility for their own learning to avoid behavioural problems

---

>**PAIR AND GROUP WORK**

*Work in pair / group*:
- exchange ideas without being on the spot 
- increase speaking time 
- extremely important 
- won't reinforce wrong learnings 

Make sure change partners often to practice different accents / personalities

**Group**: 3-4 students

**Activities**: 
- dialogues/drills
- simple questions-answers
- quick brainstorm
- peer review of written work 
- preparation before group larger 

**Monitor**:
- during group work
- help / advice / consult 

**Evaluate**:
- result
- coopearation

*Include pair work in every lesson* - give different roles (reader / presenter / leader) = Increase *participation*

>**ORGANIZING AND GROUPING STUDENTS**

*Student-centered classroom* - collaborative approach -> heavily depends on pair / group work 

**?? How to put students together ??**

- *Random groupings*
    - make name cards and shuffle them - random 
    - Can control this decision using personality/proficiancy - **streaming**: put them together according to a language ability (same/mix)

- *Assigned grouping*
    - Have those who get along to work together - benefit: good relation between students; negative: relations can change and some students may be excluded
    - Arrange by task / preference 
    - Change often pairings

>**INDIVIDUAL DIFFERENCES**


**VARK Learning System**

- **Visual learners**: 
    - learn through visual depictions / graphs / charts; 
    - difficult to follow listenings 
    - memorize with pictures

- **Aural (Auditory) learners**: 
    - learn through tutorials / audiobooks / lectures
    - remember stories
    - memorize with read out loud / verbalizing 

- **Read-Write learners**:
    - through textbooks / definitions / arrangements of info

- **Kinesthetic learners**: 
    - learn through direct experience / practice 
    - remember what done, not what said 
    - use all senses 
    - need to be active, take frequent breaks, benefit hands-on-experience

*Best* method involves varying dynamics very often - so students vary abilities 

*Example - Vocabulary learning*:
- use pictures
- make students write 
- listen in dialogues
- read story
- make game

>**SEATING ARRANGEMENTS**

Direct impact on student-centered classroom 

-> Purpose of any arrangement: max accomplishment + min problems

-> Arrange seats - foster communication 

-> Change arrangement if needed 

*Most commong ways*: 
- Orderly rows: 
    - straight rows facing teacher 
    - good for teacher-centered class
    - good test administration / presentation 
    - not good for communication 
    - no face-to-face contact 

- Horseshoe: 
    - everyone in class can see/communicate
    - ideal for teacher-led discussions / storytelling / role-play
    - not rigid as rows
    - more sharing 

- Circular:
    - strong sense of equality / involvement 
    - sharing maximized 

- Separate tables: 
    - ideal for pair/group works
    - different groups - different tasks 
    - teacher gives assistance
