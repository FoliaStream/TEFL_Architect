# CHAPTER 9 - Speaking & Writing 

>**INTRODUCTION TO SPEAKING**

Speaking / writing - output and production components 

Speaking - connected to listening -> practice following listening 

Conversation classes - popular 

--- 

>**TEACHING SPEAKING**

Aim os speech - communicate message orally so that intentions understood 

Oral production - fluency / grammar / vocabulary / pronunciation 

Effective speakers: 
- awareness social dynamics of language 
- create coherent / cohesive output 
- know when stop / interrupt and ask questions 
- know how language functions in speech acts 

---

>**DESIGN LESSON AND ACTIVITIES**

- **Step 1.** - Create context (warm-up)

Set the scene and activate background knowledge - schema activation 

- **Step 2.** - Present target language

Present key concept - speech samples while focus on target 

- **Step 3.** - Practice target language

Practice through controlled exercises / pair / group - short structured conversarions with strong monitoring 

- **Step 4.** - Produce target language 

Students use new langauge to communicate effectively - minimum monitoring and independent use 

---

>**TIPS FOR TEACHING SPEAKING**

Avoid practice speaking for sake of speaking 
- must use structure with clear conteext / learning goals 
- no open discussion without context 

Activities: 
- activity multi-directional and communicative
- activity allows students time to plan outputs
- practice activities closed tasks - finite set of possible answers 
- production activities open-ended - independent communication

Consider also students age - set output expectations 

---

>**SAMPLE SPEAKING ACTIVITIES**

- Songs: for young learners songs + gestures / images and use simple lyrics 
- Role plays: assume role character - citation / conversations in simple contexts 
- Informative gap: done in pairs, one has info, one doesn't -> negotiate exchange info 
- Prepared speeches / presentations: teacher provide structure for production - content / length / topic according to level 
- Problem solving: students given info and find solution, intermediate / high adnvaced for production 
- Open-ended discussion: students need clear idea of topic and expectations 
- Interview questionnaire: written teacher / students monitored 
- Audio-video recording: students record themselves - done without monitoring 
- Games: many to be used

>**PRONUNCIATION**

Pronunication - integral component in the communicative approach 

Proper pronunciation - problem: not a single one correct 

Accent is inevitable 

Improvement - takes long time

---

>**PRONUNCIATION FEATURES**

Speaking - Listening are linked -> share acquisition factors

Voicing / stress / rythm / intonation / reductions 

*Segmental vs Suprasegmental*:
- Segmental: 
    - work on individual phonemes (sounds) vowels / consonants 
    - teach how to sound 
- Suprasegmental: 
    - more than 1 sound 
    - stress / rythm intonation / pitch / linking / pausing 


*International Phonetic Alphabet (IPA)*:

Visual representation of individula (segmental) sounds 


---

>**STUDENT ABILITIES AND REALISTIC GOALS**

Many influences in acquiring good pronunciation 

Key factors: 
- age: 
    - if acquire late then no native pronunciation probably 
- first language: 
    - overlap with first language pronunciation - accent
    - lack of sound in first language - need fix (gap sounds)
- second language exposure / use: 
    - acquisition linked to exposure - maximize exposure 


*Setting realistic goals*

No need to strive to sound native 

Strive for comprehensible / intelligible production - communicate clearly = success

Accent is ok - make students aware 

---

>**TIPS FOR TEACHING PRONUNCIATION**

Options: 

- *Entire lesson on pronunciation*
    - work on extended Suprasegmentals as rythm / intonation / stress 
    - include them in longer discourse practice 
    - introduce also other skills 

- *Use discrete time slots*
    - short manageable chunks of pronunciation activities

- *Integrated practice*
    - focus on speed feature connected to language point 
    - such as listening to understand pronunciation

- *Opportuninties present themeselves*
    - teachable moments 
    - deviate from plan in response to opportunity 

Best option - mix these techniques: 
- Do need analusis and pronunciation profile of students 
- Help students being self-aware and set goals 
- Use pronunciation activities in lesson plan - regular schedule 
- Practice segmentation and suprasegmental activities
- Remind students need outside class practice 
- Goal - comprehension, no perfect speech 

---

>**SAMPLE PRONUNCIATION ACTIVITIES**

- Minimal pari exercises: words differ only 1 sound - useful for practicing contrasts in voicing / tense / lax vowels 
- Formation of sound: awareness on how parts of mouth work together to create sound 
- Vowel length: stretch rubber band with fingers to visualize vowel legth 
- Information gap: good practice stress/rythm/intonation - students focus on accurate production and use communicate 
- Tongue twister: lot of fun - mastery of sound is not the goal 
- Stress practice: students count syllabes/word/sentence stress - tap out syllabes 
- Poetry/Rhyme/Songs/Limericks: method to practice stress / rythm / intonation - interesting and fun 
- Humming usnig Kazoo: word/sentence intonation mimicking focus on melody 
- Assimilation practice: effect of previous / after letters on other letters 
- Recording: students record and listen own voice - self-awareness
- Dictation: read at normal speed and students try to write - sound recognition 
- Dialogues/roleplay/drama: include sounds / grammar / vocab - whole languge activity

>**ASSESSING SPEAKING**

Make sure students know on what they will be tested 

Make authentic tasks - real-world mirroring 

Quite and free of distractions environment 

Record students - grade after class 

Make sure warm up time 

Limit teacher talk time - let students talk 

*Methods oral assessment*: 
- Oral interview:n ask series questions increasing difficulty - lack spontaneity good for initial placement 
- Peer/group discussion: 
    - reliable measure of oral production 
    - mirror natural / real converssation
    - more than one student evaluated at once 
- Voice recording / speech samples: provide write / listen / visual stimulus and students react according 
- Oral presentation: effective for academic / business 
- Role-plays: done in pairs - students must be used to it - no true level acquisition 


*Speaking rubrics*

Teach / raise awareness / assess then on sub-skills of speaking 

Sub-skills - use specific pre-set rubric to focus on sub-skills

- Organize ideas for audience / purpose: students present ideas coherently 
- Fluency: ability to easy speak, no hesitation 
- Pronunciation: clear/accurate sounds / stress / rythm / intonation 
- Grammar vocab: use appropriate structures / words / phrases 
- Communicative competence: pair / group communication 

---

>**PROVIDE FEEDBACK SPEAKING**

Provide many feedbacks - many ways and methods 

*Immediate VS Delayed*

- Delayed
    - provieded after fact / speaking 
    - provide constructive comments 
    - no interruption 
- Immediate
    - provided during fact / speaking 
    - immediate students focus on feature 
    - no flow of conversation 
    - students apply soon corrections 

*Corrective VS Positive*
- Positive 
    - more effective when more specific 
    - supportive classroom creation 
- Corrective 
    - highlight errors 
    - can be beneficial

>**BASICS SECOND LANGUAGE WRITING**

Kind of writing teach depends on students needs - academic / creative / personal 

Tips / guidelines: 
- do need analysis - assist planning with writing sample at beginning of semester 
- students bring personal knowledge / experience in writing task 
- students do many different types of writing 
- give purpose to writing 
- clear instructions provided 
- students ability should match requirement tasks 

---

>**PROCESS APPROACH WRITING**

1. *Pre-writing / Planning*:
- brainstorming on topic with others 
- listing ideas about topic 
- cluste diagram to organize ideas 
- freewriting about any idea 

2. *First draft*
- no need for perfect 
- purpose - organize pre-writing ideas in coherent / cohesive way 

3. *Peer-review*
- students read each other draft and come up with comments / suggestions about content/organization/grammar

4. *Second draft*
- students write second draft using feedbacks

5. *Edit / revision*
- Teacher gives feedback on second draft 

6. *Final Draft*
- Students uses teacher feedback to rewrite and deliver 

---

>**ALTERNATIVES PROCESS WRITING**

Writing techniques;

- Journal writing 
    - effective for develop voice as writer 
    - focus on fluency and accuracy 
- Critical response
    - opinion about art/story/music effect
    - emphasis on fluency and critical thinking 
- Visual stimulation
    - picture basis for create description 
    - emphasis on creativity 
- Letter writing 
    - done at all age (different topic)
    - practice formal structure / format 
- Writing games 
    - complete sentences using silly prompts 
    - focus on positive dynamics

>**ASSESSING WRITING**

- Examples:

    - guided writing: use prepared prompt to produce final product - table/graph/diagram - give specifics on requirements final product

    - peer assessment: give each other feedback

- Sub-skills assessment: 
    - organizing info appropriately for task / audience 
    - development of ideas 
    - grammar and vocabulary use 
    - mechanics 

- Basic elements: 
    - directions on requirements 
    - prompt clarity relevance / length 
    - expected response communicated 
    - rubric evaluation
