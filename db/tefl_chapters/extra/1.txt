>**BUILDING COMMUNITY**

Build students into a solid team/community

*Games*: help them solve problems 

Teacher must remember hobbies / goals / background and want them to succeed

Classroom structure - *RULES* - necessary part

THe younger the students the more structure is needed

*Rules - Rewards - Punishment* are very important

**Positive vs Negative* Reinforcement:
- Positive: reward for desired behaviour - make sure positive reinforcement do not create dependency on Rewards
- Negative: increasing desired behavior by avoiding negative condition - make sure applied equally

>**ADDRESS STUDENT BEHAVIOR ISSUES**

Things can go out of hand -> Confront teachers - students misbehaving

*Appraoch / Strategies* - heavy effect on environment:
1. Determine the issue
2. Deal as soon as it appears
3. Remain alm and focused
4. Focus on actions - not students
5. Talk with student privately - always better one-on-one talk
6. Enforce rules agreed upon - first week clear rules!
7. Consult colleagues if all else fails

**Ineffectve vs Effective Teaching**

Remember the effective teachers from past

- *Always try new things*:
    - Ineffective - stuck in their ways
    - Be dynamic - reuse good activity, don't reuse same plan


- *Set the stage from first moment*:
    - Begin class = set stage for whole experience
    - better start with review from previous + clarify new topic 


- *Use class time effectively*:
    - Every second is worth
    - Students able to multitask


- *Never leave your class*:
    - Unless absolutely necessary
    - Always keep monitoring 
    - Need something - nominate volunteer (only if necessary)


- *Understand technology*:
    - Know how to use resources - many tools
    - be ready if tech fails


- *Limit teacher talk time (LTTT)*:
    - Pick most important points to focus on 
    - Cannot go through everything in one sit 
    - Cannot teach everything
    - Make students talk 

- *Manage classroom*:

    Teacher needs to organize:
    - organize students
    - give clear directions
    - plan objectives
    - set clear time limits

- *Peers = best resources*:
    - Talk to colleagues
    Work in group

- *Avoid negativity*:
    - Positive approach -> more smooth 
    - Make distance with negative behavior

- *Be a facilitator*:
    - We don't give knowledge to students
    - We help them find/construct environment where they learning
    - Let them do on their own
    - We are facilitators

**PERSONALIZE INTERACTIONS**

1. *Ways to personalize interactions*
- be intentional about addressing students names
- embrace get to know you activities
- make time for off-content communication

2. *Teaching application*
- create name card
- mix cards beginning of class
- call students using order of cards

*Example name card*
| Front | Back |
| --- | --- |
| Name | Hobbies |
| Preferred name | Language goal | 
| Pronouns | |

3. *Online modification*

Use google sheet + google forms to randomize names before class


**DEVELOP CLASS ACCOUNTABILITY**

1. *Ways to develop class accountability*
- Create class rules / expectations as group 
- Assign class rules / duties
- Have students work on personal learning goal - periodic checks

2. *Teaching application*

Assign students jobs / roles:
- describe jobs / chores to be done clearly 
- slowly let students take over these jobs
- alternate duties

*Example jobs*
    - calendar helper
    - weather helper 
    - board helper
    - paper passer
    - paper collector 

3. *Online modification*

Students jobs for online learning 
- Attendance clerk
- chat moderator
- virtual assistant
- time keeper
- breakout room leader
- tech helper



**ENCOURAGE EMPATHY AND KINDNESS**

1. *Ways to encourage empathy / kindness*
- Emphasize friendship / teamwork
- Model and encourage random acts of kindness
- Engage in compliment circle 

2. *Teaching application*

Paying compliments activity:
- Model giving compliments as everyday act
- Teach students how to give compliments in the target language
- Have them practice with "Paying Compliments" activity
- Encourage students to continue giving in daily class

*Example*
    - I like your ___ 
    - I like how you ___
    - I like it when you ___

3. *Online application*

Create form with argument to give compliments
- language skills
- family
- vocabulary knowledge
- clothes / food
- attitude


**ENCOURAGE EMPATHY AND KINDNESS**

1. *Ways to work towards shared goals*
- Enlist class in create class rule/agree
- Implement weekly challenges
- Create long-term challenge with reward

2. *Teaching application*
Implement weekly challenges:
- weekly challenges for students to work together
- when goal reached give class reward
- after many success ask students for challenges
