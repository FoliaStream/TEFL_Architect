**Piaget's Theory of Cognitive Development**

- *Sensorimotor (0-2)*
    - learn about world through reflexes, senses, movements 
    - learn things exist even if not seen 
    - realize actions have consequences 
    - experience rapid language growth 

- *Pre-operational (2-7)*
    - begin think symbilically 
    - learn use words to represents objects 
    - often egocentric and struggle see other's perspective
    - improve thinking language - still think in concrete terms 
    - master grammar of own language 

- *Concrete-operational (7-11)*
    - think logically about concrete events 
    - understand concept of conversation 
    - use inductive reasoning - more from specific info to general principle
    - struggle handle abstract thoughts

>**COGNITION AND SCHEMA**

*COGNITION*

Very young learners - lack capability to learn/analyze/describe language (metalanguage and grammar)

Older children and adults able to rap into learning strategies -> learn more vocabulary 

Classroom application - be aware of age students and select materials accodingly:
- vocabulary selection match development age 
- don't explain rules / grammar to young learners 
- check terminology 

*SCHEMA*

Piaget - schema: how children categorize process knowledge

Schema changes with person's experience / learn new things 

Children - less experience: less schema to assimilate learning new things 

Classroom application: 
- Think what life experiences learners have 
- Pick topics related to knowledge they already have

>**THE AFFECTIVE FILTER**

*Affective filter* - theory concept: emotional variables involved with success/fail in acquiring second language 

Filter + -> high anxiety / self-esteem / low motivation 

Filter - -> low inhibitions 

Incorrect to think children not susceptible to emotions - as susceptibles as adults 

Even more affected by inhibitions - make environment more comfortable 

**Characteristics of the Affective Filter**:
- *Lower affective filter*:
    - safe and become risk-takers 
    - comfortable making writing and speaking mistakes
    - empowered to interact with peers 
    - encourages answer questions 
- *Higher affective filter*:
    - lack self-confidence
    - reluctant to collab with peers 
    - stress / anxiety to perform task 
    - bored / disinterested 

Classroom application: 
- think how to encourage to relax and not to be intimidated 
- sit on knees / get on their level 
- clear expectations to be set - introduce task in structured and simple way 
- grouping allow interaction with peers 
- set behaviour policies for classroom 
- encourage risks and be strategic with error corrections

>**ATTENTION SPAN AND INPUT VARIATION**

*ATTENTION SPAN*

Big difference between young learners and adults 

Attention spans intrinsicaly linked to activity types 

Classroom application: 
- engage young learners attention spans - lesson lively engaging 
- better to use familiar routines and rotating activity types
- incorporate movement activites - TPR (total physical response)
- differentiate the way you recycle to make reperition of content more engaging 

*INPUT VARIATION*

Children need more input variation in lesson delivery and physical environment 

They lack adult capacity / different attention spans - benefit stimulation multiple senses 

Classroom application: 
- create multisensory experience for children 
- make adjustment to classroom space - desk arrangement / decorations

>**YOUNG LEARNER PROGRAM MODELS**

Vary in shape / size - depend on attitude towards english 

In EU and Asia it is common to start at 3 years old - sooner better for intonation 

Other places at 5 

*Shin - Crandall - list of program models:*

- **FLEX Programs**: foreign language exploratory or experience
    - goal: introduce children to new cultures through language learning 
    - short sessions - learn basic voca through songs / games 
    - focus: not proficiency but interest for language 

- **FLES Programs**: foreign language in elementary school 
    - incorporate language learning as part of students curriculum 
    - 45 min lessons 
    - focus: develop listening / speaking skills (older student also write and read)

- **Immersion Programs**: 
    - immerse students in english - use english for instruction for all school subjects 
    - develop english and maintan native language proficiency
    - teach subjects in english - some all subjects, others partial immersion 

- **Bilingual programs**: 
    - promote bilingualism by teaching subjects in two languages

>**CLASSROOM MANAGEMENT**

Establish classroom routine - feel safe if know what to expect, avoid stress, make sure them feel secure 

Always monitor students - make sure you know what they doing, walk around 

Always demonstrate activity - provide examples for clarity 

Keep activities short - limit 5-10 minutes, use many activities, change often 

Maintain class study unity - make class feel like they part of team, make collab games 

Teach negotiation strategies - help students feel more independent, lesson more smooth 

Alternatite quiet / moving activities - vary according to students needs, start slow and go faster 

Seek insights from local teachers - helpful local teachers, guidance in approach definition 

Create peace tabel - if fight, put chairs in corner and moderate conversation - what / when / how want what?
